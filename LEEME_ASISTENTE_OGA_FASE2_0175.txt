ASISTENTE OGA - FASE 2 - REV 0.17.5
====================================

INSTALACION
1. Cierre Sistema OGA.
2. Haga una copia de seguridad de la carpeta actual.
3. Copie el contenido de este paquete sobre la raiz de Sistema_OGA.
4. Seleccione REEMPLAZAR LOS ARCHIVOS EN EL DESTINO.
5. Ejecute Python INICIAR.py.

MODO IA AVANZADA (OPENAI)
- Sistema OGA NO necesita instalar el paquete Python openai: la integracion usa HTTPS con la API oficial.
- Configure en el servidor la variable de entorno OPENAI_API_KEY.
- Se incluye CONFIGURAR_OPENAI.ps1 para hacerlo sin guardar la clave dentro de la carpeta del programa.
- Cierre la consola y Sistema OGA despues de configurarla y abra una consola nueva.
- Modelo predeterminado: gpt-5.6-sol.
- Puede cambiarlo definiendo OGA_AI_MODEL antes de iniciar el servidor.

IMPORTANTE SOBRE FACTURACION
- La suscripcion de ChatGPT y la plataforma API son servicios con facturacion separada.
- Para usar la IA avanzada desde este servidor local se requiere una cuenta de API con facturacion habilitada y una API key.

COMPORTAMIENTO
- Si OPENAI_API_KEY esta configurada: el modelo interpreta lenguaje natural y decide que herramientas READ_ONLY consultar.
- Si la API no esta configurada, no hay Internet o la API falla: el Asistente OGA cae automaticamente al motor local de respaldo.
- Preguntas como "que proyectos hay" funcionan tambien en el motor local.
- La conversacion conserva hasta 10 mensajes recientes para entender seguimientos como "y cuales son de Nestle?".

SEGURIDAD - REGLA INVIOLABLE
- La IA NO dispone de herramientas para crear, editar, subir, reemplazar, mover, renombrar o eliminar informacion.
- Aplica tambien a administradores.
- Las herramientas conectadas son exclusivamente de consulta.
- La base de Oportunidades se abre desde el Asistente con SQLite mode=ro y PRAGMA query_only=ON.
- Una instruccion como "reemplaza este PDF" es bloqueada y no se envia como operacion de escritura.

HERRAMIENTAS READ_ONLY DISPONIBLES
- listar_oportunidades
- buscar_oportunidades
- contar_oportunidades
- obtener_oportunidad
- listar_archivos
- listar_equipos
- resumir_equipos_historicos
- buscar_similares
- estadisticas_oportunidades

EJEMPLOS
- Que proyectos hay?
- Muestrame proyectos del cliente Nestle.
- Que proyectos tienen entrada por BIG BAG y transporte en fase densa?
- Dame el ID del proyecto 3121.
- Traeme las ofertas del proyecto 3121.
- Que equipos tiene ese proyecto?
- Busca proyectos similares a la OD actual.
