HOTFIX OGA 0.17.5.2.1 - ASISTENTE OGA

Corrige el ImportError:
  cannot import name 'count_opportunities_in_ids' from 'asistente_oga.readonly'

CAUSA
La revision 0.17.5.2 actualizo local_engine.py pero el paquete de actualizacion no incluia readonly.py.
En instalaciones que no tenian exactamente la revision intermedia 0.17.5.1, ambos archivos quedaban desincronizados.

INSTALACION
1. Cerrar Sistema OGA y todas las consolas de Python que lo esten ejecutando.
2. Copiar TODO el contenido de esta carpeta sobre la raiz de Sistema_OGA.
3. Elegir Reemplazar archivos en el destino.
4. Opcional: borrar la carpeta asistente_oga/__pycache__ si existe.
5. Ejecutar: Python INICIAR.py
6. Debe mostrar: OGA 0.17.5.2.1 disponible en http://127.0.0.1:5005

Este hotfix NO modifica bases de datos, Excel, usuarios, adjuntos ni configuraciones.
Solo sincroniza el codigo del Asistente OGA y conserva el modo estrictamente READ ONLY.
